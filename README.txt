## 🛠️ How to Use & Customize

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed if you want to use the Tailwind CLI compiler. However, you can also run them instantly using the built-in Tailwind script.

### Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to your desired template folder:**
   ```bash
   cd template-1
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to view it in your browser, or open the folder in **VS Code**.
